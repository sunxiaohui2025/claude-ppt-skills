Text Only

纯文字页：用大标题承载判断

适合观点解释、背景说明、原则声明。页面要像现场讲述，而不是文档摘抄。

一个发布会式文字页不是论文页。它先给强判断，再用少量证据建立可信度。

  • 标题是观众带走的句子。
  • 正文只解释必要语境。
  • 要点控制在三条以内。
Text + Image

图文组合：左文右图

适合先讲观点，再让观众看右侧证据或产品画面。

Image + Text

图文组合：左图右文

适合从画面进入叙事，右侧负责解释意义和下一步判断。

Top Image

图文组合：上图下文

适合先给大场景，再用一句话收束图片背后的含义。

Bottom Image

图文组合：下图上文

适合先提出结论，再用下方宽图作为证据展开。

Full Image

单大图页：让一张图成为全场记忆点

只保留少量标题文案，避免把大图降级成背景装饰。

# Indigo Porcelain Style Pack

靛蓝瓷。深蓝科技风格，适合 AI、研究、技术发布会、架构分享和产品技术路线图。

## Tokens

- Background: `#0a1f3d`
- Main text: `#f1f3f5`
- Secondary text: `#b9c7d8`
- Muted: `#93a4b8`
- Accent: `#79b8ff`
- Support: `#d7e7ff`
- Panel: `rgba(241,243,245,.055)`
- Line: `rgba(215,231,255,.16)`

## Visual Personality

- 深蓝瓷器感，理性、技术、冷静。
- 可使用网格、轨道、节点、能力栈和系统图。
- 科技感强但不赛博，不使用高饱和大面积霓虹。

## Best For

- AI 产品发布。
- 技术架构。
- 研究结论。
- Demo Day 技术说明。
- 平台能力和路线图。

## Rules

- 标题用瓷白，关键词用亮蓝。
- 架构页优先使用分层、系统图、路径线。
- 卡片透明、细边框、可有轻微玻璃感。
- 线条和节点可以多一点，但不要抢标题。
- 封面可使用右侧轨道/节点图，内容页要保持稳定。

# White Stage Style Pack

纯白展台。白色产品发布风格，适合 AI 产品发布、Demo Day、产品演示、功能介绍和客户演示。

## Tokens

- Background: `#ffffff`
- Main text: `#111111`
- Secondary text: `#58606b`
- Muted: `#6b7280`
- Accent: `#0f766e`
- Panel: `#ffffff`
- Soft panel: `#f7faf9`
- Line: `#e5e7eb`

## Visual Personality

- 纯白、锋利、留白多，像产品展台。
- 重点靠字号、留白、细线和产品 UI 区域，不靠背景装饰。
- 产品截图、流程、Demo 步骤是主角。

## Best For

- 产品发布。
- Demo Day。
- 产品路线图。
- 功能介绍。
- 投资人或客户演示。

## Rules

- 页面要敢于留白，不要填满。
- 卡片可以更白、更干净，但不要圆角过大。
- Demo 页优先左侧步骤 + 右侧产品界面/模拟 UI。
- 当前步骤或核心能力用绿色强调。
- 背景保持纯净，最多用极淡边框和浅色产品窗口。

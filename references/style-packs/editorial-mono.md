# Editorial Mono Style Pack

黑白专刊。杂志 editorial 风格，适合强个人观点、行业观察、专家演讲、私享会和思想型分享。

## Tokens

- Background: `#f7f5f0`
- Main text: `#141414`
- Secondary text: `#4d4a45`
- Muted: `#777069`
- Accent: `#141414` as italic serif / heavier editorial text treatment, not plain black text only.
- Panel: `rgba(255,253,250,.50)`
- Line: `rgba(20,20,20,.18)`

## Visual Personality

- 像一篇高级杂志封面文章。
- 强排版、强字重、强留白，不依赖彩色装饰，但要使用杂志化元素：斜体关键词、黑色细横线、页眉栏目标签、编号强调。
- 适合个人表达、判断、引文、专栏式章节。

## Best For

- 带强烈个人风格的演讲。
- 行业观察和观点分享。
- 创始人/专家演讲。
- 私享会。
- 黑白杂志风主题。

## Rules

- 优先使用大标题、大引文、短段落、编号说明。
- 标题可使用衬线字体气质，关键词不要加黑色背景或下划线；优先用斜体、字重或 editorial label 强调。
- 卡片不使用圆角，不要产品 UI 感。
- 内容页像杂志跨页：左侧大引文，右侧短解释。
- 强调色就是黑色本身，避免额外彩色破坏风格。
- 每页可以有很轻的 `MONO / FEATURE` 栏目标记或长短横线，营造杂志专栏感。

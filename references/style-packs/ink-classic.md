# Ink Classic Style Pack

墨水经典。通用深色高端风格，适合商业发布、行业内部讲话、线下分享、私享会，以及用户不知道选择什么深色风格时。

## Tokens

- Background `--cream`: `#0a0a0b`
- Panel `--porcelain`: `#161412`
- Main text `--ink`: `#f1efea`
- Secondary text `--stone`: `#bfb8ac`
- Muted `--muted`: `#8f8a82`
- Accent `--clay`: `#c8a46a`
- Secondary accent `--accent-2`: `#8d9aa8` — charts second voice
- 其余线条 / 软底 / 阴影由模板用 `color-mix` 自动派生，不要手写 rgba。

## Visual Personality

- 黑色剧场感，像商业发布会主屏。
- 少量淡金线条建立秩序和高级感。
- 使用纸张颗粒、暗纹、细线，不使用重渐变和霓虹。
- 内容页像高级杂志跨页，不要堆满卡片。

## Best For

- 商业发布。
- 行业内部讲话。
- 闭门分享。
- 高层观点页。
- 章节转折和结论收束。

## Rules

- 大标题优先，标题最多 2 行。
- 强调色面积控制在 10-18%。
- 卡片边框细，背景透明，避免厚重模块感。
- 观点页可使用居中大判断 + 细金线 + 三个短解释点。
- 动效只用于封面、章节和封底，内容页克制。

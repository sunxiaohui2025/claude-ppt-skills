# Porcelain Green Style Pack

青瓷技术档案。低饱和青瓷底色搭配黑白杂志化文字系统，适合平台架构、流程设计、Agent 能力说明、可信 AI 分享。

## Tokens

- Background `--cream`: `#bdd4cc`
- Panel `--porcelain`: `rgba(255,255,255,.30)` 的轻纸面层次
- Main text `--ink`: `#050505`
- Secondary text `--stone`: `rgba(0,0,0,.72)`
- Muted `--muted`: `rgba(0,0,0,.46)`
- Accent `--clay`: `#050505`，仅用于黑色标签、节点、编号和少量装饰图形
- Secondary accent `--accent-2`: `rgba(0,0,0,.34)`
- Display font `--font-display`: Bodoni 72 / Didot / Georgia / Songti SC

## Visual Personality

- 更像技术档案、系统 dossier，而不是互联网产品页。
- 青瓷色只提供空间氛围，内容必须保持黑白克制。
- 非常适合流程图、系统图、章节页和观点页。
- 可以有细竖线、坐标感节点、轻量圆弧，但不要出现绿色字体。

## Best For

- AI 平台 / Agent 平台能力介绍。
- 技术宣讲、架构设计、解决方案分享。
- 数据流、工作流、系统地图类内容。
- demo day 中偏工程化的一段。

## Rules

- 所有标题、重点字、正文、编号统一使用黑色或浅黑色。
- 不要使用绿色标题、绿色关键词、绿色 label 字体。
- 允许黑底白字的栏目签，强化杂志感。
- 图形节点、流程线、卡片边框一律走透明黑体系。
- 背景可以有很轻的晕感，但不做明显渐变。

# 版式模板索引
请以 `assets/html-template/dune-sample-deck.html` 作为标准版式参考文件，该路径为**相对于项目根目录**的相对路径。

内容生成遵循**模板优先**原则，具体规则如下：
1. 从下方模板列表中选用一种幻灯片版式。
2. 将对应版式的DOM结构复制至 `sources/slide-XX.html` 文件中。
3. 仅替换文本、数值、标签及常规重复节点。
4. 保留原有组件类名与层级结构不变。
5. 禁止新增自定义通用结构，例如 `content-block`、`statement-slide`、`section-slide` 或自定义行内网格样式。
6. 禁止发明新的 `layout-*` 别名。除 `layout-cover`、`layout-agenda`、`layout-subtitle-band`、`layout-delivery-flow`、`layout-closing` 外，其他 `layout-*` 都视为错误。

错误示例：`layout-split`、`layout-statement`、`layout-cinematic-section`、`layout-flow-cards`、`layout-icons-grid`、`layout-compare-2`。

正确做法：保持模板真实类名，例如 `split`、`statement-stage`、`icons-grid`、`compare-2`、`flow-cards`、`thanks`。

## 可用幻灯片模板
- `01 封面`：样式 `layout-cover`；左侧大标题、作者/时间标签、右上角环形装饰、右下角标识图标的开篇页
- `02 目录`：样式 `layout-agenda` + `agenda-runway`；支持3-5行章节，内容较多时需分页
- `03 纯文本`：样式 `text-page-clean`；包含标题、核心观点、简短说明文字，最多搭配3条项目符号
- `04 左文右图`：样式 `split`；左侧文字，右侧配图/佐证素材
- `05 左图右文`：样式 `split reverse`；左侧配图/佐证素材，右侧文字
- `06 上图下文`：样式 `stack-vertical`；上方图片，下方精简文字
- `07 上文下图`：样式 `stack-vertical`；上方文字，下方图片
- `08 全屏大图`：样式 `full-image`；主体为整幅图片，仅添加少量悬浮文字
- `09 图标+文字`：样式 `icons-grid`；3-4组图标配说明文案
- `10 双卡片布局`：样式 `cards-2`；两个等宽面板
- `11 三卡片布局`：样式 `cards-3`；三个等宽面板，仅放置简短文案
- `12 四格网格`：样式 `grid-4`；四个紧凑内容模块（2x2）。四个简短并列项希望排成一行时，改用 `cards-4`
- `13 多列列表`：样式 `multi-columns`；三列简短列表内容
- `14 左右对比`：样式 `compare-2`；常规内容与高亮内容对照展示
- `15 优劣分析`：样式 `compare-2`；优势与风险对比
- `16 新旧对比`：样式 `compare-2`；原有状态与全新状态对照
- `17 对比矩阵`：样式 `table`；3-4个维度的矩阵表格
- `18 横向时间线`：样式 `timeline-h`；页面横向排布3-4个阶段
- `19 纵向时间线`：样式 `timeline-v`；页面纵向排布3个阶段
- `20 步骤流程`：样式 `flow`；4-5个流程步骤
- `21 循环逻辑`：样式 `split` + `cycle`；文字搭配循环示意图
- `22 主干分支`：样式 `branch`；核心观点 + 分支列表
- `23 树形层级`：样式 `tree`；根节点与多级子节点
- `24 辐射结构`：样式 `radial`；中心主体 + 外围关联节点
- `25 嵌套层级`：样式 `nested`；多层级嵌套容器结构
- `26 柱状图`：样式 `chart-card` + `bars`；分类数据对比
- `27 饼图`：样式 `pie-wrap`；占比数据展示
- `28 折线图`：样式 `line-chart`；数据趋势展示
- `29 组合图表`：样式 `combo`；双图表组合展示
- `30 观点陈述`：样式 `statement-stage`；居中展示结论/核心观点。非章节类陈述页保留 `statement-rule` 样式，主观点 `h2` 字号与章节标题同级，并必须用 `<span class="title-accent">...</span>` 或 `<span class="accent">...</span>` 高亮最关键主题词
- `31 问题解决方案`：样式 `problem-solution`；问题与方案成对展示
- `32 目标与规划`：样式 `goal-plan`；突出目标数字 + 配套规划列表
- `33 副标题栏+卡片`：样式 `layout-subtitle-band`；醒目副标题栏 + 三张辅助卡片
- `34 交付流程`：样式 `layout-delivery-flow` + `flow-cards`；用户/前端/平台全链路交付流程
- `35 结尾页`：样式 `thanks`；固定为最终页面，包含致谢标识、居中文字及作者信息，**禁止使用** `statement-rule` 样式
- `36 单行四卡`：样式 `cards-4`；四个简短并列卡片排成一行，每张卡片文案必须很短
- `37 案例改造`：样式 `case-transform` + `case-panel`；旧痛点 → 新方案左右对照，底部可加 `bottom-conclusion` 结论条
- `38 系统全景`：样式 `system-map` + `system-col`/`system-core`/`system-node`；左侧输入、中央引擎、右侧输出
- `39 复用主张`：样式 `reuse-hero` + `goal-number`/`reuse-tags`；巨型指标或主张 + 应用场景标签行

章节页说明：章节页不要使用 `layout-cinematic-section`。应使用 `statement-stage` 章节结构，并包含 `section-ghost-number`、`kicker`、大标题和一句短副标题；不要放卡片、列表、流程或证明对象。

## 选用规则
1. 封面、结尾页必须分别使用模板 `01` 和 `35`。
2. 内容页是如果是要写一个目录，请选择目录页模板，并且只用一次该模板，后面内容不要再选择目录页面的模板。
2. 章节分隔页统一采用当前模板规定的分栏版式，不得使用普通内容版式。
3. 内容无配套佐证素材时，选用 `03 纯文本` 或 `30 观点陈述`。
4. 内容为两组对立/对照信息时，选用 `14`、`15`、`16`；禁止自定义双列行内网格。
5. 内容包含三项并列观点时，选用 `11`；若文案篇幅较长，需分页或改用 `31`。
6. 内容涉及运作模式、工作交接流程时，选用 `34`。
7. 内容体现新旧场景/逻辑对比时，选用 `16` 或 `31`。
8. 若页面需要手动添加 `style="font-size..."`、`style="display:grid..."` 等行内样式，说明版式选用错误。

## 允许修改范围（复制模板后）
- 替换标题、观点、标签、日期、数字及卡片内文字
- 在原有结构与容量范围内，增删同类型重复节点
- 切换卡片高亮类名，如 `hot`、`colored-card`
- 将图片占位框替换为正式图片资源
- 编辑图表数据：修改SVG坐标、柱体高度、图例文字

容量要求：
- 同一组卡片必须等高，不能让内容最多的卡片单独撑高。
- 每张卡片的辅助说明尽量控制在 16-28 个汉字；流程卡片控制在 20-34 个汉字。
- 四个流程/卡片项不能出现最后一个掉到第二行的情况；四流程可用 `flow-cards` 四卡片变体并隐藏箭头，长内容改用 `grid-4`。
- 章节标题不要随意换行；只有超过约 18 个汉字或实际渲染溢出时，才按语义插入一个 `<br>`，最多两行。
- 一句话观点页不是章节页，不包含 `section-ghost-number`；它的主观点应足够大，且必须有一个主题色关键词高亮。
- 图文页图片框默认按 16:9 大画面处理；不要把文字列压得太窄，如果正文折行过多，缩短正文或拆页。

## 禁止操作
- 不得将原有组件替换为 `content-block`
- 未同步更新 `base.css`、本索引文件及校验工具时，禁止新增版式名称
- 禁止把真实组件类改写成模型自造的 `layout-*` 别名
- 禁止使用大量行内CSS控制布局、间距、配色及字体样式
- 投屏演示幻灯片，正文字号不得使用 `1rem` 小字体
- 章节分隔编号下方，禁止额外添加内容
